## Topshiriq
- 1. Loglarni filtrlash
    > /var/log/syslog faylidan faqat oxirgi 50 ta "error" so‘zini o‘z ichiga olgan qatorlarni chiqaring. (Katta/kichik harf farqi bo‘lmasin)
- 2. Disk bo‘sh joyini tekshirish
    > Shunday Bash skript yozingki: Agar / diskining bandlik foizi 80% dan oshsa, disk_alert.txt fayliga xabar yozsin: "Disk space is critically high". Aks holda "Disk usage is OK" deb yozsin.
